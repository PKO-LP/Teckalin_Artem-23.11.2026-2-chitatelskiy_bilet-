# Передача инструкция и выводы

Проект: Читательский дневник (Python + Tkinter)
Версия: 0.1.1

## Комплект и версия

Передаётся комплект версии `0.1.1` в папке `Комплект_0_1_1`, содержащий:
- `app.py` (исправленная версия `0.1.1`);
- `logo.png` (обязательный файл логотипа);
- `README.md` (пользовательская инструкция для получателя);
- папку `Передача_программы` с комплектом проектной и тестовой документации (`00`–`08`).

## Шаги инструкции

1. Полностью распаковать архив с папкой `Комплект_0_1_1`, сохранив `app.py` и `logo.png` в одной папке.
2. Убедиться, что на компьютере установлен Python 3 с модулем Tkinter.
3. Открыть папку `Комплект_0_1_1` в VS Code (или перейти в неё в терминале) и выполнить `python app.py` (Windows: `py app.py`, Mac/Linux: `python3 app.py`).
4. Использовать кнопки «Добавить книгу» (до дневной цели 5 книг), «Сменить статус» (`Запланировано` -> `Читаю` -> `Дочитано`) и «Сбросить» для полного обнуления сессии.

## Результат и помощь

Ожидаемый результат запуска: окно «Читательский дневник 0.1.1» с корректно работающей блокировкой дневной цели на 5-й книге и полным сбросом всех счётчиков и статуса. По вопросам запуска и работы обращаться к ответственному за поддержку (Текалин Артём, рабочие дни 09:00–18:00, контакты указаны в `README.md` и `07_Поддержка.md`).

## Показ

Заказчику продемонстрированы: запуск версии `0.1.1`, добавление книг с фиксацией даты и времени, срабатывание блокировки «Дневная цель: 5» ровно на 5-й книге, циклическая смена статусов с подсчётом дочитанных книг и полный сброс всех показателей кнопкой «Сбросить».

## Приёмка

Проведены приёмочные и регрессионные испытания (`04_Проверки.md`), дефект `DEF-01` подтверждён закрытым. Выпуск `0.1.1` соответствует всем требованиям `ТРЕБОВАНИЯ.txt` и готов к эксплуатации.

## Ограничения

- Счётчики и статус хранятся только в оперативной памяти до закрытия окна и не сохраняются на диск.
- Отсутствуют ввод названий книг, поиск, база данных и авторизация пользователей.
- Счётчик «Дочитано книг» фиксирует количество переходов общего статуса в «Дочитано».
