## Версия и среда

Проверяемая версия: `0.1.1` (`После_исправления/app.py`).
Среда проверки: ОС Windows / Linux, Python 3 с модулем Tkinter, запуск из VS Code Terminal (`python После_исправления/app.py`).

## Регрессионная проверка

Выполнена проверка всех базовых функций версии `0.1.0`:
- пошаговое увеличение счётчика книг на 1 до границы дневной цели;
- циклический переход статусов `Запланировано` -> `Читаю` -> `Дочитано` -> `Запланировано`;
- увеличение счётчика «Дочитано книг» на 1 при каждом переходе в статус «Дочитано»;
- корректное отображение даты в формате `ДД.ММ.ГГГГ ЧЧ:ММ`;
- закрытие окна крестиком без ошибок в терминале.
Регрессионных дефектов не выявлено.

## Критерии приёмки

Выпуск `0.1.1` считается принятым, если пройдены все тесты `TC-01`–`TC-04` и регрессионные проверки без критических и высоких дефектов, в окне указана версия `0.1.1`, а комплект содержит рабочий `app.py`, `logo.png` и документацию.

## Что реально проверено

Выполнен полный цикл ручного тестирования исходной версии `0.1.0` (зафиксирован дефект `DEF-01`) и исправленной версии `0.1.1` по всем пунктам `ТРЕБОВАНИЯ.txt` (пп. 1–8), а также проверен запуск копии приложения без `logo.png` (`Копия_для_проверки`) и после его возврата.
