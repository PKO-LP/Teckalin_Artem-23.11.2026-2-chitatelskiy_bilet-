# Читательский дневник (версия 0.1.1)

Учебное настольное приложение на Python + Tkinter для учёта прочитанных книг в рамках дневной цели.

## Подготовка
- Убедитесь, что установлен Python 3 с модулем Tkinter.
- **Важно:** файлы app.py и logo.png должны находиться в одной папке.

## Запуск
Откройте папку Комплект_0_1_1 в терминале или VS Code и выполните:
```bash
python После_исправления\\app.py
```

## Функции программы
1. **Добавить книгу** — увеличивает счётчик книг на 1 и фиксирует дату и время добавления. При достижении дневной цели (5 книг) кнопка блокируется.
2. **Сменить статус** — переключает состояние чтения: `Запланировано -> Читаю -> Дочитано -> Запланировано`. При переходе в Дочитано увеличивается счётчик дочитанных книг.
3. **Сбросить** — обнуляет все счётчики, сбрасывает дату и возвращает статус к `Запланировано`.

## Ограничения
- Данные хранятся в оперативной памяти только во время текущей сессии и не сохраняются на диск при закрытии окна.
